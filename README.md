
# FitMarket

Sitio web responsivo de una tienda deportiva, desarrollado como
proyecto académico para la materia Aplicaciones Web.

## Descripción

FitMarket presenta un catálogo demostrativo de equipos de gimnasio
y suplementos deportivos, además de información sobre un servicio
de entrenamiento personal.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3: variables, Flexbox, Grid y media queries
- JavaScript: menú adaptable, filtro de productos y validación
  del formulario
- Git y GitHub para el control de versiones

## Accesibilidad y diseño responsivo

- Navegación con enlaces semánticos y foco visible.
- Campos de formulario asociados a sus etiquetas.
- Mensajes de validación y estados accesibles.
- Imágenes con textos alternativos.
- Diseño mobile first para diferentes tamaños de pantalla.

## Ejecución

1. Clona o descarga este repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Ejecuta `index.html` con Live Server.

## Limitaciones

El catálogo utiliza datos demostrativos. El formulario valida
la información en el navegador, pero no envía solicitudes a
un servidor ni procesa pagos reales.
